# acarmucahit/homebrew-tap

Homebrew formulae for my macOS tools. Everything here builds from source on your machine.

```bash
brew install acarmucahit/tap/napbar
```

| Formula | Description |
| --- | --- |
| [napbar](https://github.com/acarmucahit/napbar) | Menu bar app that puts your Mac to sleep after a chosen number of minutes |
